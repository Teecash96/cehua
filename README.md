# Cehua — 策划

**Turn product ideas into structured PRDs and visual user flows in seconds.**

Cehua is a Mac desktop app built with [Glaze](https://glaze.app) that eliminates the gap between a raw idea and a first-draft PRD. Describe your product idea in plain language, and Cehua generates a concise, editable PRD and a visual user-flow diagram — ready to share, export, or build from.

## Why Cehua?

Every product person — founders, PMs, indie developers — faces the same problem: the gap between a rough idea and a structured plan is painful and slow. You stare at a blank doc, copy templates, and waste an hour formatting before you even think clearly.

Cehua is the fastest path from thought to plan.

## Features

- **AI-powered PRD generation** — describe your idea, get a structured PRD with problem, target user, features, user stories, success criteria, and more
- **Visual user-flow diagrams** — automatically generated flowcharts with connected cards, decision points, and outcomes
- **Editable output** — every generated section is fully editable inline
- **Local-first** — all plans are saved locally on your Mac, no account or internet required
- **Export anywhere** — copy as formatted text or export as Markdown
- **Light & dark mode** — full support for both, because dark mode is not optional

## How it works

1. Open Cehua and describe your product idea (or pick a built-in example)
2. Click **Generate plan**
3. Review the generated PRD and user flow
4. Edit, refine, copy, or export

## Built with Glaze

Cehua was built entirely with [Glaze by Raycast](https://glaze.app) — a platform for creating native Mac desktop apps through conversation with AI. No traditional coding required.
